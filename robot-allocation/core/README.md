## Core

Allocation logic for EverBot — domain, services, and tests.

## Layers

| Layer | Folder | Role |
|-------|--------|------|
| Domain | `src/domain/` | Robot specs and allocation rules |
| Services | `src/services/` | Level 1–4 use cases |
| Tests | `src/tests/` | Domain tests first (TDD) |

`web/` (later) is the user interface on top of services.
